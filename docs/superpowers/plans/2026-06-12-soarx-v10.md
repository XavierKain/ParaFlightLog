# SoarX V10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformer ParaFlightLog en SoarX V10 — app standalone (nouveau bundle ID), sans Appwrite, local-first avec CloudKit, navigation simplifiée à 4 onglets, backup enrichi des traces GPS.

**Architecture:** Refonte profonde sur la branche `V10`. Suppression de la couche cloud Appwrite (14 services, ~17 vues), nouvelle racine d'app sans auth, modèles SwiftData rendus compatibles CloudKit avec fallback local. Watch et Widget conservés, identifiants renommés.

**Tech Stack:** SwiftUI, SwiftData (+CloudKit), WatchConnectivity, HealthKit, WidgetKit, Open-Meteo. Xcode 26.5, simulateurs iOS 26.x.

**Vérification standard (chaque tâche)** :
```bash
xcodebuild -scheme ParaFlightLog -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' build 2>&1 | grep -E "error:|BUILD"
```
Attendu : `BUILD SUCCEEDED`. (La Watch et le Widget sont embarqués dans ce scheme.)
